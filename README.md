# Archiwum Akt Dawnych Miasta Kraśnika (XVI–XVIII w.)
## Cyfrowy Portal Kompendiów Źródłowo-Genealogicznych

Zbiór kompletnych, autonomicznych kompendiów źródłowo-genealogicznych z ksiąg miejskich radzieckich, wójtowsko-ławniczych i wieczystych dawnego Kraśnika (województwo lubelskie), opracowanych na podstawie zasobu **Archiwum Państwowego w Lublinie** (zespół 35/40/0: *Akta miasta Kraśnika*).

### ⚙️ Funkcjonalności kompendiów HTML
Każde z kompendiów stanowi w 100% samodzielną aplikację typu Single-Page Application (SPA):
- **Wyszukiwarka dynamiczna (Instant Search):** Natychmiastowe filtrowanie nazwisk, imion, zawodów, miejscowości i ról społecznych.
- **Pulpity statystyczne:** Wykresy i metryki społeczno-gospodarcze (struktura cechowa, patrycjat, topografia przedmieść).
- **Tablice rejestru skanów:** Pełne odwzorowanie paginacji i zawartości każdej karty.
- **Edycja krytyczna i monografie:** Wyczerpujące syntezy historyczno-źródłowe.
